# jtsai-post-media

Image drop for Jump The Shark AI social posts.

Claude's automations put post images here (one folder per post, named `YYYY-MM-DD-topic`) so Postiz can pull them into draft posts for LinkedIn, Facebook, Instagram and Threads. Nothing here is posted automatically; Dave approves every post in Postiz.

Everything in this repo is public. Only put images here that are meant to be posted.
